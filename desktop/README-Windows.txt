Total IPTV Pro Desktop (Windows)

Install (pick one):
  - Unzip the Windows zip and run TotalIptvPro\TotalIptvPro.exe
  - Or use the installer/MSI if you have one

Playback:
  Install VLC for Windows from https://www.videolan.org/ (recommended).
  Settings still offer Auto / VLC / mpv / ffplay.
  mpv/ffplay work if they are on PATH.

Data:
  Prefs/favorites/resume: %APPDATA%\total-iptv-pro\
  In-app updates install to: %LOCALAPPDATA%\TotalIptvPro\ (or total-iptv-pro\app\)

Troubleshooting — no sound while playing:
  Often VLC is muted in Windows Volume Mixer even if Speakers are not.
  1) Play a channel so VLC opens.
  2) Right-click the speaker icon → Open volume mixer.
  3) Unmute VLC / raise its slider.
  4) In VLC: Audio → Audio Device → pick the speakers you use.

Troubleshooting — volume mixer won't open:
  Windows Settings may be stuck.
  1) Task Manager → end Settings, try again.
  2) Or Win+R → sndvol → Enter.
  3) Or Settings → System → Sound → Volume mixer.

UI/settings match the Ubuntu desktop app.
